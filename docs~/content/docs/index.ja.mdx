**Unity の軽量セーブシステム。**
MemoryPack ベースのバイナリシリアライズで、ゲームデータを高速かつ安全に保存します。

## 特徴

- ⚡ **高性能なシリアライズ** — Cysharp の MemoryPack を使った高速なバイナリシリアライズ/デシリアライズ。
- 🔒 **暗号化対応** — 保存データを暗号化し、改ざんや閲覧を防ぎます。
- 🧩 **シンプルな API** — ビルダーパターンで保存/読み込みフローを一目で構成できます。
