**Unity 的轻量存档系统。**
基于 MemoryPack 的二进制序列化，快速、安全地保存游戏数据。

## 特性

- ⚡ **高性能序列化** — 使用 Cysharp 的 MemoryPack 进行高速二进制序列化/反序列化。
- 🔒 **支持加密** — 对存档数据加密，防止篡改和查看。
- 🧩 **简洁的 API** — 用构建者模式一目了然地组织保存/读取流程。
