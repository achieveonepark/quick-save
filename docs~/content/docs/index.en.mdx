**A lightweight save system for Unity.**
Fast, safe game data persistence powered by MemoryPack binary serialization.

## Features

- ⚡ **High-performance serialization** — Fast binary serialize/deserialize using Cysharp's MemoryPack.
- 🔒 **Encryption support** — Encrypt saved data to prevent tampering and inspection.
- 🧩 **Concise API** — Compose save/load flows at a glance with a builder pattern.
