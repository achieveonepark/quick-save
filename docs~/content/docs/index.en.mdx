**A lightweight save system for Unity.**
Save your game data quickly and safely with MemoryPack-based binary serialization.

## Features

- ⚡ **High-performance serialization** — Fast binary serialization/deserialization using Cysharp's MemoryPack.
- 🔒 **Encryption support** — Encrypt saved data to prevent tampering and inspection.
- 🧩 **Concise API** — Compose your save/load flow at a glance with the builder pattern.
