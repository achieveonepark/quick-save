# Quick Save

**Unity 경량 저장 시스템.**
MemoryPack 기반 바이너리 직렬화로 빠르고 안전하게 게임 데이터를 저장하세요.

## 특징

- ⚡ **고성능 직렬화** — Cysharp의 MemoryPack을 사용한 고속 바이너리 직렬화/역직렬화.
- 🔒 **암호화 지원** — 저장 데이터를 암호화해 변조와 열람을 방지합니다.
- 🧩 **간결한 API** — 빌더 패턴으로 저장/로드 흐름을 한눈에 구성합니다.
